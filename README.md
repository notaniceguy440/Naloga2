<h3>Funkcionalnosti:</h3>

<ul>
  <li><b>Vnosna polja:</b> Username, Full name, Country, Email, Phone number in Password.</li>
  <li><b>Izbira spola:</b> <code>RadioGroup</code> z možnostma Male in Female.</li>
  <li><b>Pogoji uporabe:</b> Potrditveno polje (Agree with Terms &amp; Conditions).</li>
  <li><b>Prilagodljivost:</b> Vsebina v <code>ScrollView</code> za manjšo velikost zaslonov.</li>
  <li><b>Prikaz podatkov:</b> Večvrstično pogovorno okno <code>AlertDialog</code> ob potrditvi.</li>
</ul>
